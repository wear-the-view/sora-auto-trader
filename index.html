🤖 SORA AUTO TRADER v0.5 Web

Androidのブラウザだけで使える、CSV過去価格バックテスト。GitHub Pagesから保存済み実価格データを読み込み、CSV取り込みにも対応。口座登録・課金不要。

実資金の注文機能はありません。 公開価格APIからの自動取得を試せます。ブラウザの通信制限やAPI側の制限で失敗する場合はCSVを使ってください。サンプルデータは架空で、実際の相場・利益予測ではありません。AI学習モデルは未搭載で、移動平均ルールの検証版です。

① 市場データ

データ種別に注意：「架空サンプル」は動作確認専用です。実データが取得できた場合は市場・期間・出典を明記します。画面が開けることとAPI接続成功は別です。

CSV形式: date,open,high,low,close（OHLC推奨）。date,close のみでも検証可能ですが、ギャップ・約定の再現は限定的です。時系列は古い順・新しい順どちらでも可。

CSVの計算は端末内で実施します。オンライン取得時は外部APIに通信します。リロードすると読み込みデータは消えます。CSVは数千行程度を推奨。

② 公開済みの過去価格を読み込む

GitHub Actionsが保存した日足の過去データを読み込みます。初回はGitHub Actionsを手動実行してください。GOLDは金先物（GC=F）で、現物XAUUSDとは異なります。BTCはBTC/USD、ドル円はUSD/JPY（Frankfurterの参考為替レートは取引価格ではありません）。価格APIは予告なく仕様変更・アクセス制限される場合があります。ブラウザから外部の金融APIには直接アクセスしません。データ更新はGitHub Actions側で行います。

GitHub Pagesで公開して使ってください。GitHub Actionsが未実行・失敗した場合はCSV読み込みで検証できます。

オンライン接続が必要です。file://で開くとブラウザによって通信が拒否されることがあります。失敗時はCSVで代用してください。

③ 売買ルールと費用

ロングのみ・レバレッジなし・全額相当のポジション。終値で信号判定→次の足の始値で執行（終値だけのCSVは次足終値を代用）。往復コストの半分をエントリー・決済で控除。保有中の価格変動を反映してドローダウンを測定。強制停止は次足の始値で決済するため上限超過の可能性があります。

期間分割では前半を学習用、後半を検証用にします。売買ルールの自動最適化は未実装です。検証期間の成績を見てルールを何度も調整すると、未知データとしての価値が失われます。
